Satellite Launch System: Digital Twin Mission
Projekt rakietowego systemu wynoszenia małego satelity na niską orbitę
okołoziemską, obejmujący projekt rakiety, profil lotu oraz sekwencję separacji, tworząc
cyfrowego bliźniaka (digital twin), który symuluje i odwzorowuje wszystkie te elementy
oraz umożliwia analizę przebiegu misji, z uwzględnieniem optymalizacji masy rakiety
przy jednoczesnym osiągnięciu orbity.
Opis wyzwania
Celem zadania jest stworzenie cyfrowego bliźniaka (Digital Twin) rakietowego
systemu wynoszenia małego satelity na niską orbitę okołoziemską (LEO).
Projekt powinien obejmować:
● projekt rakiety nośnej
● model lotu rakiety
● profil misji
● sekwencję separacji
● symulację przebiegu lotu
● analizę osiągnięcia zadanej orbity
Zadaniem uczestników jest zaprojektowanie uproszczonego systemu, który umożliwi
przeprowadzanie symulacji misji przed rzeczywistym lotem oraz analizę wpływu
parametrów rakiety na powodzenie misji.
Zakres projektu
Projekt może zostać wykonany w dowolnej technologii i formie, np.:
● aplikacja desktopowa
● aplikacja webowa
● środowisko symulacyjne
● skrypt/program obliczeniowy
● integracja z OpenRocket lub podobnym narzędziem
Dopuszczalne jest wykorzystanie:
● OpenRocket
● Scilab
● Python
● MATLAB/Simulink
● Unity
● oraz innych oprogramowań według potrzeb własnych
Minimalne wymagania
Projekt powinien zawierać:
1. Model rakiety
Uwzględniający przynajmniej:
● masę
● silnik
● podstawowe parametry aerodynamiczne
● strukturę rakiety
2. Symulację lotu
Uwzględniającą:
● trajektorię lotu
● wysokość
● prędkość
● zużycie paliwa
● stabilność lotu
3. Sekwencję misji
Np.:
● start
● separacja stopni
● separacja ładunku
● osiągnięcie orbity
4. Element „Digital Twin”
System powinien umożliwiać:
● zmianę parametrów rakiety
● ponowne wykonywanie symulacji
● analizę wpływu zmian na przebieg misji
Super extra dodatki wpływające na podwyższenie oceny projektu :
● wizualizacja 3D
● dashboard telemetryczny
● AI/ML do optymalizacji parametrów
● interaktywny interfejs użytkownika
● inne kreatywne pomysły uczestników wpływające na jakość prezentowanego
pomysłu
Ograniczenia
Projekt nie musi odwzorowywać pełnej fizyki orbitalnej w sposób profesjonalny lub
przemysłowy-liczy się koncepcja, kreatywność oraz działający prototyp.
Dopuszczalne są uproszczone modele matematyczne i symulacyjne.
